# Operative System Simulation using Generative AI
A Python-based OS simulator that focuses on core operating system concepts, including process management, memory allocation, file handling, and resource scheduling

The project provides an interactive interface to visualize system behavior and understand how operating systems coordinate processes and manage limited resources

Tools used:
1. Tkinter
2. ChatGPT
3. Deepseek R1
4. Claude
5. V0 AI
